UI development harness — not the Aurelia browser. It exists to check that components can be built from the same design tokens the real Chromium WebUI uses. A harness preview is never evidence that the browser works: nothing here is the shipped chrome://aurelia implementation.

Design tokens

Values come from packages/design-tokens/tokens.json through node tools/design/generate-tokens.mjs. If a swatch looks wrong, fix the token and regenerate — never the generated CSS.
