HOSTED_CONSTRAINED_EXPERIMENT - one-shot trigger
================================================

This file exists only to start the single controlled run of
.github/workflows/chromium-hosted-constrained-experiment.yml.

Why: the automation credential the repository is worked with cannot create
workflow_dispatch events - the GitHub API answers

    HTTP 403: Resource not accessible by integration
    POST /repos/ankbuitv/browser/actions/workflows/{id}/dispatches

(see docs/CI-SECURITY.md). The workflow is still manual-only by design; this
push is the one documented exception, and the `push:` block that listens for
changes to this file is removed again as soon as the run has started.

Committing any change to this file after that removal does nothing: the
workflow will be `workflow_dispatch` only, which is the intended steady state.
