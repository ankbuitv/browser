HOSTED_CONSTRAINED_EXPERIMENT - one-shot trigger (temporary)
============================================================

Starts the controlled run of
.github/workflows/chromium-hosted-constrained-experiment.yml, because the
automation credential cannot create workflow_dispatch events:

    HTTP 403: Resource not accessible by integration
    POST /repos/ankbuitv/browser/actions/workflows/{id}/dispatches

Removed again once the run has FINISHED - not while it is in flight, because
editing the workflow's trigger set cancels the run that is flying.

Run 7
-----
Run 1: died in 30 s on two measurement bugs.
Run 2: reached the sync, failed after ~18 min, could not say why.
Run 3: cancelled by the commit that retired this trigger mid-flight.
Run 4: died in 1 s on a `gclient` that did not exist yet.
Run 5: the sync finished in an hour, then the DEPS hook that downloads the
  pinned Visual Studio toolchain failed - with nothing left to retry with.
Run 6: the constrained sync finished in 19 minutes. The toolchain hook then
  said, in plain terms:

    401 Anonymous caller does not have storage.objects.list access to the
    Google Cloud Storage bucket ... chrome-wintoolchain
    No downloadable toolchain found. In order to use your locally installed
    version of Visual Studio to build Chrome please set
    DEPOT_TOOLS_WIN_TOOLCHAIN=0.

  Chromium's packaged Windows toolchain is Google-internal (depot_tools'
  win_toolchain README: "requires authentication with @google.com
  credentials"), so DEPOT_TOOLS_WIN_TOOLCHAIN=1 was never going to work here.

This run builds with the Visual Studio on the image instead, and installs the
one Windows SDK the pin demands - 10.0.28000.0, read out of the checkout
rather than hard-coded - because the image carries 10.0.26100.0 and
setup_toolchain.py asks vcvarsall.bat for the pinned version by name.
